🏋️ Project Name

FitLog – Workout Tracking & Planning Application

📖 Short Description

FitLog is a modern fitness tracking application that allows users to explore workouts, view detailed exercise information, create a personalized daily workout plan, and save workouts for later. The application provides an intuitive user experience with responsive design, sorting functionality, and workout management features.

🛠️ Technologies Used
Next.js
React
TypeScript
Tailwind CSS
DaisyUI
React Context API
React Toastify
React Icons


✨ Key Features
1. Comprehensive Workout Library

Browse a collection of workouts with essential information such as duration, calories burned, equipment required, and difficulty level.

2. Detailed Workout Pages

Each workout includes a dedicated details page containing descriptions, muscle groups, instructions, equipment, sets, reps, ratings, and other exercise information.

3. Personalized Workout Planning

Users can add workouts to their daily plan, track total workout duration and calories, and manage their exercise routine efficiently.

4. Save Workouts for Later

Favorite workouts can be saved separately for quick access without adding them to the current workout plan.

5. Advanced Sorting Options

Workout plans and saved workouts can be sorted by duration, calories burned, or rating to help users organize exercises according to their preferences.

🚀 Additional Features
6. Responsive User Interface

The application is fully responsive and optimized for mobile, tablet, and desktop devices, ensuring a consistent experience across different screen sizes.
